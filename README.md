## 📱 | Projeto React Native para consulta de CEPs.

> Este repositório tem como foco armazenar o projeto **FindCep** desenvolvidos com **React Native**, com o objetivo de praticar e aprimorar habilidades em desenvolvimento mobile multiplataforma.

## 🎯 Objetivo do FindCep
- O projeto FindCep tem como objetivo permitir a busca rápida e precisa de endereços a partir de um CEP informado, consumindo uma API pública para obter dados como rua, bairro, cidade e estado, de forma prática e intuitiva.
  
## 🚀 Tecnologias Utilizadas
- React Native
- JavaScript
- Expo
